一、需求背景

Vireal 当前已具备后端基础能力和后台管理能力，但面向最终用户的 H5 创作入口尚未设计。仅有 API 和后台无法完成用户获客、体验验证和内容生产闭环，因此需要补充一个手机浏览器可直接访问的 H5 前端。

目标用户希望用很低成本生成娱乐化内容，例如头像、写真感图片、朋友圈素材、社交平台短视频或个人形象视频。如果一进入页面就强制登录，会增加首次体验阻力；因此第一版采用“先体验配置、点击生成时登录”的策略。

模型侧需要明确分工：视频生成使用 Seedance，图片生成使用 Seedream。产品 UI 不直接暴露复杂模型概念，而是通过“创作意图、提示词、参考图、尺寸、时长、人物一致性”等用户能理解的配置项组织生成体验。

二、需求目标

目标类型 描述 衡量指标 目标值
体验目标 用户进入 H5 后无需注册即可理解产品能力，并能快速填写生成需求。 首屏到点击生成的转化率 首版目标不低于 25%
登录目标 只在用户有明确生成意图时触发 Apple/Google 登录，降低前置阻力。 生成触发后的登录完成率 首版目标不低于 60%
生成目标 视频和图片各提供 2 次免费额度，帮助用户完成首次 AI 内容产出。 登录用户首次生成成功率 首版目标不低于 70%
留存目标 作品统一沉淀，支持下载、删除、再次生成，让用户回到作品页管理结果。 作品页访问率 首版目标不低于生成成功用户的 80%
运营目标 后续可通过后台配置控制模型开关、免费额度、推荐示例和风格策略。 关键配置可运营化比例 首版至少覆盖免费额度、推荐提示词、默认规格

三、用户与使用场景

用户 A：社交头像玩家

希望把自拍或普通照片变成更有质感的写实头像，用在微信、微博、小红书、Discord 或其他社交平台。关注生成速度、头像好不好看、能否下载。

用户 B：娱乐短视频尝鲜者

看到 AI 视频玩法后想快速试一下，用一句话或一张参考图生成短视频。关注是否简单、有趣、效果是否适合分享给朋友。

用户 C：轻度内容创作者

偶尔需要生成朋友圈素材、短视频封面、人物形象视频或社媒配图。比普通用户更关注尺寸、风格和人物一致性，但仍不希望被复杂参数打断。

用户 D：回访作品管理者

已经生成过内容，重新打开 H5 想找历史作品、下载结果、删除不满意内容，或基于旧作品再次生成。

核心场景

  • 用户在手机浏览器打开 H5，看到 AI 视频页，浏览推荐玩法后输入一句提示词。
  • 用户上传参考图，希望生成保持人物一致性的短视频或写实头像。
  • 用户点击生成，系统发现未登录，弹出 Apple/Google 登录弹窗。
  • 用户登录成功，系统继续创建生成任务，并跳转到作品页查看生成状态。
  • 用户在作品页下载成功结果；失败作品展示原因，允许再次生成并返还额度。

六、核心操作主线与基础逻辑

主线 1：未登录用户生成视频

进入打开 H5，默认 AI 视频 Tab，看到暗色能量创作台。
填写输入 prompt，或点击“连接”“浪漫时刻”模板自动回填。
配置上传参考图或角色图，选择 5/10/15 秒时长。
登录点击生成，弹出 Apple/Google 登录。
提交登录成功后校验视频免费次数和能量成本，创建视频生成任务。

主线 2：未登录用户生成图片

切换用户切到 AI 图片 Tab。
填写输入写实图片 prompt，选择尺寸，可上传参考图。
登录点击生成时触发登录弹窗。
提交登录成功后校验图片免费次数，创建图片任务。
查看跳到作品 Tab，成功后提供下载。

主线 3：作品再次生成

  • 用户在作品页点击“再次生成”。
  • 系统读取该作品的原 prompt、类型、尺寸、时长、参考图和人物一致性配置。
  • 视频作品跳回 AI 视频 Tab，图片作品跳回 AI 图片 Tab，并自动填充原参数。
  • 用户可修改参数后再次点击生成。
  • 再次生成需要重新校验对应类型额度；如果前一次失败并已返还额度，则重试不额外扣除返还前的失败次数。

额度扣减规则

  • 视频免费额度和图片免费额度独立计算，每个登录账号各 2 次。
  • 点击生成并成功创建生成任务后扣减 1 次对应类型额度。
  • 任务失败时返还本次额度，并在作品页保留失败作品。
  • 任务成功后不返还额度，用户可下载结果。
  • 未登录状态不显示完整账号信息，但可在生成按钮旁提示“登录后可免费生成 2 次”。

登录触发规则

  • 首次进入 H5 不弹登录。
  • 填写表单、上传参考图、展开高级配置均不要求登录。
  • 只有点击“生成视频”或“生成图片”时，如果用户未登录，才弹出登录弹窗。
  • 登录弹窗包含 Apple 登录、Google 登录和关闭按钮。
  • 用户关闭登录弹窗后停留在当前生成页，保留已填写内容。
  • 登录成功后继续提交当前生成任务，并跳转作品 Tab。

七、数据流向与接口依赖

能力 前端输入 后端 / 模型依赖 返回与落点
Apple 登录 Apple 授权结果、identity token 或授权 code。 后端 Apple 登录 API，负责验证 Apple 身份并签发 H5 登录态。 返回 access token、用户信息、剩余额度。
Google 登录 Google 授权结果、id token 或授权 code。 后端 Google 登录 API，负责验证 Google 身份并签发 H5 登录态。 返回 access token、用户信息、剩余额度。
视频生成 prompt、参考图、人物一致性、尺寸、时长。 后端生成任务 API；模型侧使用 Seedance 视频能力。 返回作品 ID 和生成中状态，前端跳转作品 Tab 轮询或刷新。
图片生成 prompt、参考图、人物一致性、尺寸、写实风格。 后端生成任务 API；模型侧使用 Seedream 图片能力。 返回作品 ID 和生成中状态，成功后作品可下载。
作品管理 筛选状态、作品 ID、删除或再次生成动作。 后端作品列表、详情、删除和重新生成接口。 返回作品列表、作品状态、下载地址或失败原因。
运营配置 H5 启动时拉取。 已有 key-value 配置接口或新 H5 配置接口。 推荐 prompt、默认尺寸、默认时长、免费额度文案、模型开关。

外部模型参考

  • Seedance 2.0：定位为音视频联合生成模型，适合作为视频生成能力来源。
  • Seedream：定位为图像生成模型，适合作为图片生成能力来源。
  • PRD 中不直接固化第三方 API 请求字段，后续以后端适配层输出的稳定接口为准。

八、异常与边界处理

场景 处理规则 用户提示
未登录点击生成 弹出 Apple/Google 登录弹窗，不清空当前表单。 登录后即可开始生成，当前内容已保留。
用户取消登录 关闭弹窗，停留当前 Tab，生成任务不提交。 已取消登录，生成前需要先登录。
免费额度不足 阻止任务提交，后续可引导付费或等待运营策略。 当前类型免费次数已用完。
参考图上传失败 提示格式、大小或网络问题；允许重新上传。 图片上传失败，请换一张清晰图片重试。
生成任务失败 作品页保留失败卡片，展示失败原因，返还额度，支持再次生成。 生成失败，已返还本次额度，可以再次生成。
作品为空 展示空状态和去生成按钮。 还没有作品，去生成你的第一张图片或第一条视频。
下载失败 提示重试；必要时打开新页面展示资源。 下载失败，请检查网络后重试。
模型服务不可用 任务标记失败或排队失败，不扣除成功额度；记录错误供后台查看。 生成服务暂时不可用，请稍后再试。
