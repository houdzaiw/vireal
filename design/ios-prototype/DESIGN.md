# Vireal iPhone 页面与交互设计

面向现有 Vireal 用户的 iPhone 内测客户端，保留网页的效果目录和账户资产，让用户从灵感浏览进入照片创作，并在同一账户内管理生成任务和作品。Android、iPad 专门布局、桌面端、充值、订阅与社区不属于首版。

## 品牌和原生交互

以当前 H5 v1.2 为视觉基线：深色背景、青色身份、大幅效果媒体、编号渐变占位图。媒体缺失时显示占位，真实客户端不得将演示动画作为某个效果的真实预览。

原生实现使用 SwiftUI，默认最低 iOS 17；系统支持的新导航材质由系统组件适配，不给内容卡片叠加多层玻璃效果。底部使用三栏 TabView，每栏保留自己的 NavigationStack。效果详情、创建、任务和作品详情进入导航栈；照片选择、确认与分享使用系统呈现方式。

| 元素 | 设计约定 |
| --- | --- |
| 参考尺寸 | iPhone 393 × 852 点；支持 375、390、430 点宽和更大字体 |
| 品牌色 | 青色 `#71d8ed`、主操作 `#b7f2ff`，深色背景 `#090b0d` |
| 字体 | 系统字体，标题、正文与说明映射 Dynamic Type，不照搬网页小字号 |
| 内容边距 | 20 点；间距采用 4、8、12、16、20、24、32 点 |
| 触控 | 主按钮高 52 点，图标和其他操作至少 44 点 |
| 安全区 | 内容、主按钮和标签栏避开状态栏、刘海和底部手势区域 |
| 动效 | 页面切换约 200 ms；尊重减少动态效果和增强对比度 |
| 图标 | 原生采用对应 SF Symbols；原型使用内置 SVG 展示同类语义 |

开发参考 `design-tokens.json`。颜色建立 Asset Catalog Color Set，提供高对比变体；正文及系统标签采用语义颜色。以深色媒体体验为主，照片选择器和系统分享等仍遵循系统设置。

## 页面与导航

| 页面 | 内容与操作 | 进入和离开 |
| --- | --- | --- |
| 发现 | 分类横向滑动、精选效果、双列卡片、余额入口。首卡突出推荐内容 | 游客可浏览；点效果进入详情；底部进入作品和我的 |
| 效果详情 | 预览、介绍、照片数量、时长、费用起点；固定底部主操作 | 未登录时点使用进入登录，完成后接续创建；下架时返回发现 |
| 邮箱登录 | 邮箱输入、验证、错误和重试；沿用 Clerk 已有邮箱方式 | 记录来源效果；业务会话初始化成功后再进入目标页 |
| 创建视频 | 一张或两张照片位、替换和移除、时长、金币消耗、照片使用确认 | 选图、授权和服务端条件满足后打开生成确认；提交后去任务详情 |
| 生成进度 | 提交、排队、生成、保存与终态；效果摘要和任务编号 | 可返回作品；已完成可进入详情；状态未知只查询原任务 |
| 我的作品 | 全部、进行中、已完成筛选；刷新；文字标明失败与过期 | 点击进行中或失败任务去任务详情；完成和过期记录去作品详情 |
| 作品详情 | 播放、保存、分享、媒体有效期、删除记录 | 保存触发相册权限；分享下载好的作品文件；删除后返回列表 |
| 我的 | 昵称、已验证邮箱、金币入口、帮助和设置 | 游客看到登录入口，个人数据在登录后读取 |
| 我的金币 | 当前余额、最近金币流水；充值关闭说明 | 返回原页；内测版不展示第三方收款按钮 |
| 账户设置 | 修改昵称、当前会话说明、退出 | 退出清空本机个人页面和临时照片，不撤销其他设备会话 |
| 使用与隐私说明 | 照片处理用途、服务规则、媒体期限及联系信息 | 上线前替换为正式条款，不能直接使用原型说明作为政策 |

原型外侧导航、状态选择和说明面板只用于设计审阅，不属于实际 App。示例的“体验另一个演示账户”也不进入真实产品。

## 核心操作流程

### 登录与恢复

启动时先展示公共目录。Clerk 恢复成功不等于业务账户就绪；每个新会话完成 `/auth/session` 初始化后才读取个人数据。恢复中使用占位，避免短暂显示别人的缓存或登录页闪烁。

创作触发登录时保存效果与目标页，成功后接续。业务服务返回注册关闭时说明“注册尚未开放”；不把它误判成邮箱验证码错误，也不循环发验证码。已有用户与首次注册分开处理。多设备可以使用同一业务账户；退出当前会话不退出其他设备。

### 照片与生成

采用系统照片选择器，首版不增加相机入口。依据 `input_image_count` 展示照片位；更换效果时清空不匹配的照片。照片先在本地预览，用户确认生成后上传。读取到过期上传 ID 时要求重新选择或上传，不能创建任务。

时长只展示 `variants` 返回的规格；费用取所选规格的 `coin_cost`。确认框展示效果、时长和金币。原生端将照片转换为后端可接受的格式并处理方向，大小限制取实际配置；原型的 15 MB 仅为本机预览限制。

同一确认尝试只生成一个幂等标识并保存到提交结果明确为止。点击、请求超时、令牌刷新或重进页面都不能偷偷更换标识。重新尝试同一 POST 时复用原始参数和幂等标识；用户明确开启下一次创作才建立新草稿。

### 任务与作品

真实客户端前台按 3 秒间隔查询当前任务；连续失败采用 6、12、30 秒退避，到达终态停止。进入后台暂停轮询；返回前台先刷新一次。作品列表首次进入和下拉时读取；只在存在进行中任务时每 10 秒刷新。首版不承诺后台常驻，不新增推送。

不显示服务端未提供的百分比或预计完成时间。待确认状态用原任务查询和同一幂等请求核对，不提供“再生成一次”快捷操作。媒体播放链接到期时重读详情，使用新链接；作品本身过期则不再尝试下载。

原生保存与分享都通过受保护的下载接口取得文件。只保存所选作品；下载失败时保持原页，不能弹出成功提示。用户拒绝相册权限时仍允许系统分享。删除前确认，进行中和待确认任务不能删除。

## 状态与恢复

| 状态 | 页面表现 | 恢复操作 |
| --- | --- | --- |
| 加载中 | 内容骨架和可读状态说明，不展示旧账户的余额 | 等待结果；超时给手动重试 |
| 目录为空 | 说明当前分类无效果，提供其他分类入口 | 返回精选或重读目录 |
| 作品为空 | 提供开始创作入口；筛选为空时说明筛选范围 | 改筛选或返回发现 |
| 网络断开 | 保留当前选择和草稿，不自动重传照片 | 用户重试；恢复后重读状态 |
| 服务关闭或地区不支持 | 允许浏览与授权的历史读取，关闭新上传和生成 | 重新查询可用性；不引导充值绕过限制 |
| 金币不足 | 显示所需金币与余额，禁用生成 | 内测版说明充值未开放 |
| 额度或并发耗尽 | 展示服务端剩余额度及重置时间，暂停新生成 | 待重置或进行中任务完成后刷新 |
| 效果下架 | 保留必要说明，禁用该效果 | 返回发现选择其他效果 |
| 登录失效 | 清除个人展示数据，保留无敏感的目标效果 | 重新登录；不自动重放付费提交 |
| 提交结果不明 | 标记正在确认，保留同一请求标识 | 查询原任务或同参数同标识核对 |
| 生成失败 | 展示失败原因和真实退币状态 | 查看金币流水，不自动重开生成 |
| 媒体过期 | 保留记录，关闭播放、保存和分享 | 返回作品，可删除终态记录 |

## 原型和原生实现的区别

原型模拟 Clerk、金币、任务和数据隔离，不联网。默认演示账户有 128 金币和历史作品，新示例账户为空；演示任务约 12 秒完成，品牌动画只有 5 秒，均不代表真实服务能力。

原生端真实生成仍由服务开放、身份、地区、额度、费用与运行状态共同决定。生产生成 Worker 尚未恢复的历史验收问题，需要在实际接入时复核并处理。此套设计不自动开放注册、充值或模型调用。
