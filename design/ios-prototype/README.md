# Vireal iPhone 客户端设计交付

这套设计将当前 Vireal 移动网页整理为 iPhone 客户端体验，保留深色、青色品牌与效果目录，采用发现、作品、我的三栏导航。首版目标是内测登录、选图、生成和作品管理，充值关闭。

## 查看原型

打开本目录的 `index.html` 即可体验，也可以在项目根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory design/ios-prototype
```

浏览器访问 [本地原型](http://127.0.0.1:4178/)。服务器只监听本机，不发布到公网。直接打开文件时，部分浏览器可能限制本地视频播放和下载，使用本地预览可避免此问题。

首次进入是游客。推荐体验：发现 → 随光起舞 → 使用此效果 → 使用示例邮箱 `demo@vireal.example` → 演示验证码 `123456` → 使用演示图片 → 勾选照片授权 → 生成。任务约 12 秒完成，可在作品中播放与保存演示片段。

左侧可直接检查各页；为方便审阅，选择需要登录的页面时会使用演示账户。右侧可切换断网、余额不足、服务关闭、提交待确认和媒体过期等状态。手机宽度下，页面选择在顶部，状态控制和设计说明在手机界面下方。

## 交付内容

| 文件 | 用途 |
| --- | --- |
| `index.html`、`styles.css`、`app.js` | 无需构建的本地交互原型 |
| `DESIGN.md` | 页面、导航、操作流程与状态说明 |
| `API.md` | 已有接口、请求字段、登录适配和服务端缺口 |
| `ACCEPTANCE.md` | 原型检查与后续真实客户端验收 |
| `design-tokens.json` | 品牌色、间距、尺寸及原生字体映射 |
| `assets/` | 本地演示图与 5 秒品牌渐变动画 |
| `checks/verify.cjs` | 浏览器交互检查，可复跑并生成截图 |

## 数据与服务边界

原型全部使用内存演示数据。没有 Clerk SDK、服务器请求、持久化邮箱、真实上传、付费模型调用或支付。页面设置 `connect-src 'none'`，禁止脚本联网；视频和占位图均为本地文件。选中的照片通过临时本机引用预览，退出账户、重置或关闭页面时清理。

金币、效果名称、规格、保留期限和处理时间用于说明设计，不代表线上目录或价格。新示例邮箱模拟空账户，不赠送演示金币；默认示例账户有 128 演示金币和历史记录，供完整检查。

此目录保留早期网页交互原型；真实 Swift + UIKit 客户端现位于仓库 `ios/`。原型自身没有修改业务服务、部署或业务开关。登录和生成是否可以接入线上，必须按 `API.md` 与 `ACCEPTANCE.md` 单独验证。

## 检查原型

需要 Node.js、Playwright 及浏览器。检查脚本优先复用当前项目 `h5` 已安装的 Playwright，不自行安装依赖。

```sh
node design/ios-prototype/checks/verify.cjs
```

默认检查 `http://127.0.0.1:4178/`。可通过 `PROTOTYPE_URL` 指定其他本地地址，通过 `PLAYWRIGHT_MODULE_PATH` 指定已有 Playwright 的模块搜索路径。检查结果和截图写入 `checks/results/`。
