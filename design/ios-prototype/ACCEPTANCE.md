# Vireal iPhone 验收清单

原型验收验证页面和本地演示逻辑；真实客户端验收验证 Clerk、服务器、生成和系统能力。两类结果不能相互替代。

## 原型检查

| 场景 | 通过条件 |
| --- | --- |
| 游客浏览 | 初始不要求登录；分类可切换，详情与照片数量一致 |
| 登录接续 | 进入创作后模拟邮箱验证；错误验证码显示错误，正确验证码接续原效果 |
| 照片数量 | 单图效果一个位、双图效果两个位；缺任一照片不能生成 |
| 使用照片 | 本地图片可替换和移除；不支持或不可解码图片有提示 |
| 授权与规格 | 未确认照片使用权不能生成；时长变化同步更新金币 |
| 提交去重 | 一次确认只增加一个任务并扣一次演示金币；回到同草稿不会重复生成 |
| 生成过程 | 排队、生成、保存、成功可到达；离开页面仍能从作品找到原任务 |
| 状态未知 | 查询原任务保持同一任务，不增加任务或金币流水 |
| 作品操作 | 筛选可用；已完成可播放和保存本地片段；删除需确认 |
| 媒体过期 | 没有播放器、保存或分享入口，仍能看记录和删除 |
| 金币与退出 | 充值禁用；退出清除临时照片；重新登录仍有本次内存中的账户记录 |
| 账户隔离 | 切换新演示账户后余额、作品和昵称不串号 |
| 异常预览 | 加载、空内容、断网、服务关闭、下架、金币不足、额度耗尽、身份失效与失败可到达 |
| 数据边界 | 所有资源来自本地；没有外部请求、Clerk 请求、照片上传、真实生成或支付 |
| 适配 | 桌面、375/393/430 点手机宽度下无横向溢出；主要按钮可达 |
| 可访问性 | 有语义标签、焦点样式、键盘可操作弹窗、减少动态效果支持；真机 VoiceOver 另验 |

复跑方法见 README。浏览器检查结果记录在 `checks/results/summary.json`，页面截图也在该目录。检查只覆盖其明确记录的场景，未通过浏览器模拟证明原生 SDK 或线上服务。

## 真实客户端登录与账户

- [ ] 使用对应环境的 Clerk Native API、合法应用标识及 audience，在 iPhone 完成邮箱验证与会话恢复。
- [ ] 业务初始化成功后读取本人资料、钱包和作品，账户 ID 与网页一致；不按邮箱字符串自动合并账户。
- [ ] 新用户遇到注册关闭时得到正确提示，已有用户按规则登录；验证后的邮箱仍由服务端核验。
- [ ] 原生缺失 `azp` 合法令牌可验证；错误来源、空或 null 来源、错误签名、issuer、audience、过期与 pending 会话均拒绝。
- [ ] 会话撤销立即失去个人接口权限；退出 App 当前会话后网页另一个合法会话仍可用。
- [ ] 登录取消、SDK 恢复超时与业务初始化失败不会丢失目标效果，也不会闪现其他用户数据。
- [ ] 401/403 分类处理准确，业务准入关闭不会触发无限重登。

## 真实上传与生成

- [ ] API 与 Worker 版本和数据库结构一致，先满足既有服务恢复、地区、账户、费用及额度条件。
- [ ] 系统选图后处理方向、HEIC 转换和实际大小限制；用户未确认前不上传。
- [ ] 只使用本人未过期上传 ID；异账户、错数量和过期照片被后端拒绝。
- [ ] 有效效果与规格来自目录；详情到提交之间下架或变价时正确刷新并重新确认。
- [ ] 双击、重连、App 切后台、SDK 刷新和请求超时均不重复收费或创建任务。
- [ ] 首次提交无响应时以相同参数及幂等标识核对；不自动重开新的付费生成。
- [ ] 额度为零、并发占用、余额不足、预算关闭和地区限制有可理解提示。
- [ ] 前后台切换正确暂停和恢复查询，不编造百分比；失败和退币独立显示。

## 真实作品与系统能力

- [ ] 播放链接短期过期可重新获取；作品保留期限结束返回 410 并关闭媒体操作。
- [ ] 下载请求携带权限，完成后才提示保存成功；错误、断网与取消不显示成功。
- [ ] 相册权限按需请求，拒绝后可继续使用其他功能；文件可通过系统分享面板分享。
- [ ] 仅终态作品可以删除；删除后列表刷新、文件访问及账户数据符合后端结果。
- [ ] 375 点屏幕、大字体、VoiceOver、增强对比度及减少动态效果下，主要操作可完成。
- [ ] 临时文件、照片引用和个人缓存按账户隔离，在退出与注销时按正式策略清理。

## 内测完成和上架前置

内测完成需要预发布真机证据及获准的真实生成闭环；仅看到登录页面或本地演示完成不算通过。没有授权和服务恢复时，不为验收擅自提交真实付费模型任务。

App Store 阶段另外完成苹果内购、账户注销、正式条款和隐私说明、媒体处理披露、内容安全与年龄要求、审核账户和正式运行监控。内测原型不宣称这些已具备，也不更改生产开放或收款状态。
